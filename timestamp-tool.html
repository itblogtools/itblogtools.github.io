Unix 타임스탬프 변환기

타임스탬프와 실제 날짜·시간을 서로 변환해요. 초 단위와 밀리초 단위 모두 지원합니다.

📖 사용법 보기 ▸
1상단 카드에서 현재 시각의 타임스탬프를 실시간으로 확인할 수 있어요.
2타임스탬프 → 날짜 칸에 숫자를 입력하면 실제 날짜·시간으로 자동 변환돼요.
3날짜 → 타임스탬프 칸에서 날짜와 시간을 선택하면 초/밀리초 단위 타임스탬프가 나와요.
4결과 옆 '복사' 버튼으로 필요한 값을 바로 가져다 쓰세요.
💡 API 응답이나 로그에서 본 숫자가 10자리면 '초' 단위, 13자리면 '밀리초' 단위일 가능성이 높아요.

이 도구는 무엇을 하나요?

Unix 타임스탬프 변환기는 유닉스 타임스탬프(1970년 1월 1일 UTC 자정부터 경과한 초 또는 밀리초)와 실제 날짜·시간을 서로 변환해주는 도구입니다. 타임스탬프를 입력하면 로컬 날짜, UTC 시간, 요일까지 함께 보여주고, 반대로 날짜와 시간을 선택하면 초 단위·밀리초 단위 타임스탬프를 동시에 계산해줍니다. 현재 시각의 타임스탬프도 실시간으로 표시됩니다.

왜 만들었나요?

API 응답이나 서버 로그를 확인하다 보면 1735689600 같은 숫자로 시간이 표기되어 있는 경우를 자주 마주칩니다. 이 숫자가 정확히 언제를 의미하는지 머릿속으로 계산하기는 쉽지 않고, 자릿수(초 단위인지 밀리초 단위인지)를 헷갈려서 엉뚱한 날짜로 오해하는 경우도 흔합니다. 개발자들이 API 디버깅이나 로그 분석 중 이런 숫자를 빠르게 사람이 읽을 수 있는 날짜로 확인할 수 있도록 만들었습니다.

이런 상황에 유용해요

  • API 응답에 담긴 타임스탬프 값이 정확히 언제를 의미하는지 확인하고 싶을 때
  • 서버 로그의 타임스탬프를 사람이 읽을 수 있는 날짜로 빠르게 변환하고 싶을 때
  • 특정 날짜와 시간을 코드에 사용할 타임스탬프 값으로 미리 계산해두고 싶을 때
  • 초 단위와 밀리초 단위 타임스탬프를 헷갈리지 않고 정확히 구분하고 싶을 때

사용할 때 주의할 점

타임스탬프 값이 10자리 정도면 초 단위, 13자리 정도면 밀리초 단위일 가능성이 높습니다. 단위를 잘못 선택하면 완전히 다른 연도로 계산될 수 있으니 자릿수를 먼저 확인해주세요. 이 도구는 브라우저의 로컬 시간대를 기준으로 날짜를 표시하며, UTC 값도 함께 제공하니 시간대 차이가 중요한 작업에서는 UTC 값을 활용하시길 권장합니다. 입력하신 값은 브라우저 안에서만 계산되며 서버로 전송되지 않습니다.

자주 묻는 질문

Q. 타임스탬프가 1970년으로 계산돼요.
밀리초 단위 값을 초 단위로 잘못 선택했을 가능성이 높습니다. 자릿수를 확인하고 단위(초/밀리초)를 다시 선택해주세요.
Q. 로컬 시간과 UTC 시간이 왜 다르게 나오나요?
유닉스 타임스탬프 자체는 시간대와 무관한 절대값이지만, 이를 사람이 읽는 날짜로 표시할 때는 시간대에 따라 다르게 보입니다. 한국은 UTC보다 9시간 빠릅니다.
Q. 1970년 이전 날짜도 변환할 수 있나요?
네, 음수 타임스탬프를 입력하면 1970년 이전 날짜로도 변환됩니다.

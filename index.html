IT 도구모음

심심할 때 하는 미니게임부터 세금·연금 계산기, 자주 쓰는 개발자 도구까지, 필요한 걸 골라 바로 써보세요. 전부 브라우저에서 바로 실행되고, 별도 설치나 회원가입은 필요 없습니다.

IT 도구모음은 일상에서 반복적으로 마주치는 "이거 계산 좀 해줬으면", "이거 변환 좀 됐으면" 싶은 순간들을 모아, 검색 한 번으로 바로 해결할 수 있도록 만든 무료 웹 도구 모음입니다. 처음에는 개발자가 자주 쓰는 JSON 포맷터나 정규식 테스터 같은 도구 몇 개로 시작했지만, 실제로 주변 사람들에게 필요한 걸 물어보고 하나씩 채워나가다 보니 지금은 퇴직금·국민연금·상속세 같은 생활 밀착형 계산기부터 가벼운 심리테스트, 미니게임까지 40여 종이 넘는 도구를 갖추게 됐습니다.

이 사이트를 만들면서 가장 중요하게 생각한 원칙은 세 가지입니다. 첫째, 회원가입이나 로그인 없이 바로 써볼 수 있어야 한다는 것. 둘째, 입력한 정보는 브라우저 안에서만 처리되고 서버로 전송되거나 저장되지 않아야 한다는 것. 셋째, 단순히 숫자만 뱉어내는 게 아니라 왜 그런 결과가 나오는지, 어떤 점을 더 확인해야 하는지까지 함께 설명해야 한다는 것입니다. 그래서 각 도구 페이지마다 계산 원리와 주의사항, 자주 묻는 질문을 함께 정리해두었으니, 결과값만 보고 넘어가지 마시고 아래 설명도 한 번씩 읽어보시길 권해드립니다.

도구는 크게 다섯 카테고리(심심할 때 · PC&게임 · 보안 · 개발도구 · 생활도구)로 나뉘어 있고, 상단 메뉴나 아래 카테고리 라벨을 눌러 원하는 영역으로 바로 이동할 수 있습니다. 특정 계산기 하나만 쓰러 오셨더라도, 비슷한 카테고리에 있는 다른 도구들도 한 번씩 둘러보시면 의외로 쓸모 있는 걸 발견하실 수도 있어요.

자주 묻는 질문

Q. 정말 회원가입 없이 전부 무료로 쓸 수 있나요?
네. 이 사이트의 모든 도구는 회원가입이나 로그인 없이 바로 사용할 수 있고, 별도의 이용료도 없습니다. 운영비는 페이지 내 광고로 충당하고 있습니다.
Q. 입력한 정보(연봉, 재산, 비밀번호 등)가 어딘가에 저장되나요?
대부분의 도구는 입력값을 브라우저 안에서만 계산하고 서버로 전송하지 않습니다. 다만 환율 조회나 IP 정보 확인처럼 외부 API 통신이 꼭 필요한 일부 도구는 예외이며, 이 경우 해당 도구 페이지와 개인정보처리방침에 별도로 안내하고 있습니다.
Q. 계산기 결과를 그대로 믿고 중요한 결정을 내려도 되나요?
세금·연금·대출 관련 계산기는 법령에 명시된 공식을 기반으로 하지만, 개인별 공제 항목이나 최신 법 개정 사항까지 완벽히 반영하지는 못할 수 있습니다. 결과는 대략적인 규모를 가늠하는 참고 자료로 활용하시고, 금액이 크거나 중요한 결정이라면 반드시 세무사·회계사 등 전문가나 해당 공식 기관(국세청, 국민연금공단 등)을 통해 다시 확인하시길 권장합니다.
Q. 새로운 도구를 만들어달라고 요청할 수 있나요?
네, 가능합니다. 문의하기 페이지를 통해 어떤 도구가 필요하신지 알려주시면 검토 후 순차적으로 반영하고 있습니다.
Q. 모바일에서도 똑같이 사용할 수 있나요?
네. 모든 도구는 반응형으로 제작되어 PC와 모바일 브라우저 모두에서 동일하게 사용하실 수 있습니다. 별도의 앱 설치는 필요 없습니다.

이 도구는 무엇을 하나요?

Base64 / URL 인코더·디코더는 텍스트를 Base64 형식이나 URL 형식으로 변환하거나, 반대로 변환된 문자열을 원래 텍스트로 되돌려주는 도구입니다. 방식(Base64/URL)과 방향(인코딩/디코딩)만 선택하면 즉시 결과가 나오며, 입력↔결과를 서로 바꿔서 반대 방향으로 재변환하는 기능도 지원합니다.

왜 만들었나요?

개발 관련 작업을 하다 보면 aGVsbG8=처럼 알 수 없어 보이는 문자열이나, 한글이 포함된 URL에서 퍼센트 기호가 잔뜩 붙은 형태를 마주치게 됩니다. API 인증 토큰이나 설정값이 Base64로 인코딩되어 있는 경우, 내용을 확인하고 싶어도 방법을 몰라 그냥 넘어가는 경우가 많습니다. 이런 문자열을 즉시 원문으로 확인하거나, 반대로 필요한 값을 변환할 수 있는 도구가 필요하다고 생각해 만들게 되었습니다.

이런 상황에 유용해요

  • API 문서나 응답값에서 Base64로 인코딩된 데이터의 원문을 확인하고 싶을 때
  • 인증 토큰이나 요청 데이터를 Base64로 인코딩해서 API 테스트를 진행할 때
  • 한글 제목이 포함된 게시글 링크를 URL로 안전하게 만들어야 할 때
  • 암호화된 것처럼 보이는 문자열이 실제로 Base64인지 확인하고 싶을 때

사용할 때 주의할 점

Base64는 암호화가 절대 아닙니다. 그냥 텍스트를 다른 형식으로 표현하는 방식일 뿐이라, 누구나 몇 초 만에 원문으로 되돌릴 수 있습니다. 비밀번호나 민감한 정보를 Base64로 인코딩해서 "안전하게 처리했다"고 착각하시면 안 됩니다. URL 인코딩을 하실 때는 전체 URL(https://...까지 포함)을 통째로 인코딩하시면 오히려 링크가 깨지니, 링크에 들어갈 값(파라미터) 부분에만 적용하는 것이 맞습니다.

자주 묻는 질문

Q. 이거 암호화 아닌가요? 안전한 거 아닌가요?
아닙니다. Base64와 URL 인코딩 모두 되돌릴 수 있는(reversible) 인코딩으로, 암호화 키 없이 누구나 원문으로 복원할 수 있습니다. 진짜 보안이 필요하다면 반드시 별도의 암호화 방식을 사용해야 합니다.
Q. Base64 디코딩 시 오류가 발생해요.
입력한 문자열이 유효한 Base64 형식이 아닐 가능성이 높습니다. Base64는 A-Z, a-z, 0-9, +, /, = 문자만 사용하므로 이 외의 문자가 섞여 있다면 제거 후 재시도해주세요.
Q. 입력한 텍스트가 서버에 저장되나요?
아니요. 모든 변환은 브라우저 안에서만 이뤄지며, 입력한 내용은 어디로도 전송되지 않습니다.

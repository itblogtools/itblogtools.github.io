해시 생성기

텍스트를 입력하면 SHA-1, SHA-256, SHA-512 해시값을 동시에 계산해드려요.

📖 사용법 보기 ▸
1입력창에 해시로 변환할 텍스트를 입력하세요.
2입력하는 즉시 SHA-1, SHA-256, SHA-512 세 가지 해시값이 자동으로 계산돼요.
3필요한 해시값 옆의 '복사' 버튼으로 바로 가져다 쓰세요.
💡 같은 텍스트는 항상 같은 해시값을 만들어내지만, 원문 글자 하나만 바뀌어도 해시값은 완전히 달라져요. 파일 무결성 검증에 이 원리가 활용됩니다.

이 도구는 무엇을 하나요?

해시 생성기는 텍스트를 입력하면 SHA-1, SHA-256, SHA-512 세 가지 해시 알고리즘으로 즉시 변환해주는 도구입니다. 입력하는 즉시 실시간으로 계산되며, 브라우저에 내장된 Web Crypto API를 사용해 안전하고 빠르게 처리합니다. 각 해시값은 원클릭으로 복사할 수 있습니다.

왜 만들었나요?

파일 다운로드 후 무결성을 검증하거나, 비밀번호를 코드에 저장하기 전 해시로 변환해서 확인하거나, API 서명값을 검증하는 등 해시값을 다뤄야 하는 상황이 개발 작업에서 자주 발생합니다. 매번 터미널을 열어 명령어를 입력하기보다, 텍스트를 붙여넣기만 하면 여러 알고리즘의 해시값을 한 번에 확인할 수 있는 가벼운 도구가 있으면 훨씬 빠르게 작업할 수 있다고 생각해 만들었습니다.

이런 상황에 유용해요

  • 다운로드한 파일의 체크섬(SHA-256 등)이 공식 배포처와 일치하는지 확인할 때
  • 코드에서 사용할 해시값을 미리 계산해서 테스트하고 싶을 때
  • API 요청 서명이나 웹훅 검증 로직을 테스트하고 싶을 때
  • 같은 입력값이 항상 같은 해시를 만드는지 알고리즘 동작을 확인하고 싶을 때

사용할 때 주의할 점

해시는 되돌릴 수 없는 단방향 변환입니다. 해시값만으로는 원문을 복원할 수 없지만, 비밀번호처럼 예측 가능한 짧은 문자열은 미리 계산된 해시 테이블(레인보우 테이블)로 역추적될 위험이 있습니다. 실제 서비스에서 비밀번호를 저장할 때는 단순 SHA-256이 아니라 솔트(salt)와 반복 연산이 포함된 bcrypt, Argon2 같은 전용 알고리즘을 사용해야 합니다. 이 도구는 학습과 검증 목적의 참고용이며, 입력한 텍스트는 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

자주 묻는 질문

Q. MD5는 왜 지원하지 않나요?
MD5는 이미 충돌 공격(서로 다른 입력이 같은 해시를 만드는 공격)이 실용적으로 가능하다고 알려진 취약한 알고리즘이라, 브라우저의 표준 Web Crypto API에서도 지원하지 않습니다. 새로운 용도에는 SHA-256 이상을 권장합니다.
Q. 같은 텍스트인데 공백 하나 차이로 해시가 완전히 달라요.
정상입니다. 해시 함수는 입력이 1비트만 달라져도 결과값이 완전히 다르게 나오도록 설계되어 있습니다(눈사태 효과). 이 덕분에 원문의 미세한 변조도 즉시 감지할 수 있습니다.
Q. 입력한 텍스트가 저장되나요?
아니요. 모든 계산은 브라우저 안에서만 이뤄지며, 입력한 내용은 어디로도 전송되지 않습니다.

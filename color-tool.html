컬러 코드 변환기

색상을 고르면 HEX, RGB, HSL 코드를 동시에 확인하고, 어울리는 팔레트도 함께 볼 수 있어요.

📖 사용법 보기 ▸
1미리보기 영역의 동그란 색상 선택기를 눌러서 원하는 색을 고르세요.
2또는 아래 HEX·RGB·HSL 입력창에 직접 코드를 입력해도 돼요. 어느 한 곳만 바꿔도 나머지가 자동으로 계산돼요.
3각 코드 옆 '복사' 버튼으로 원하는 형식을 바로 가져다 쓰세요.
4하단의 추천 팔레트에서 비슷한 톤의 색상 5가지를 확인하고, 클릭하면 그 색으로 바로 전환돼요.
💡 CSS 작업 중이라면 HEX나 RGB를, 디자인 도구에서 명도·채도를 조절하고 싶다면 HSL 값을 활용하시면 편해요.
🎨 추천 팔레트 (클릭해서 전환)

이 도구는 무엇을 하나요?

컬러 코드 변환기는 색상 피커로 색을 고르거나 코드를 직접 입력하면 HEX, RGB, HSL 세 가지 형식을 동시에 확인하고, 같은 색조의 5단계 팔레트를 자동으로 추천해주는 도구입니다. 세 형식 중 어느 곳에 값을 입력해도 나머지가 실시간으로 계산되며, 팔레트의 색상을 클릭하면 그 색으로 바로 전환됩니다.

왜 만들었나요?

디자인 작업을 하다 보면 같은 색을 여러 형식으로 표현해야 하는 상황이 자주 생깁니다. 포토샵이나 피그마에서는 RGB로 색을 뽑았는데 실제 웹사이트 코드에는 HEX로 넣어야 하는 경우가 대표적입니다. 또한 브랜드 컬러 하나를 정했다면 그 색을 기준으로 어울리는 배경색이나 강조색도 함께 정해야 하는데, 이를 감으로만 찾으려면 시간이 오래 걸립니다. 색상 형식 변환과 팔레트 추천을 한 번에 해결하기 위해 만들었습니다.

이런 상황에 유용해요

  • 디자인 툴에서 뽑은 RGB 색상을 CSS 코드용 HEX로 바꿔야 할 때
  • 브랜드 컬러 하나로 어울리는 배경색·보조색 팔레트를 만들고 싶을 때
  • HSL의 명도(L) 값만 조절해서 같은 색조의 밝은/어두운 버전을 만들고 싶을 때
  • 블로그나 홈페이지를 직접 꾸밀 때, 색상 코드 때문에 작업이 막히지 않게 하고 싶을 때

사용할 때 주의할 점

색상은 모니터나 화면 설정에 따라 미묘하게 다르게 보일 수 있습니다. 이 도구에서 확인한 색이 실제 인쇄물이나 다른 기기에서는 살짝 다르게 보일 수 있다는 점을 참고해주세요. 또한 텍스트와 배경 색상을 함께 정하실 때는 단순히 예쁜 조합을 넘어서 명암 대비가 충분한지도 함께 고려해야 가독성이 확보됩니다. 이 도구는 색상 코드 변환에 집중한 도구라 접근성(명암비) 검사 기능은 제공하지 않으니, 필요하시면 별도의 명암비 검사 도구를 함께 활용해주세요.

자주 묻는 질문

Q. HEX 코드 앞의 #은 꼭 붙여야 하나요?
입력창에서는 없어도 자동으로 인식하지만, 실제 CSS 코드에서 사용하실 땐 꼭 포함해야 합니다.
Q. HSL 값은 언제 사용하는 게 좋나요?
명도나 채도만 살짝 조절하고 싶을 때, 또는 같은 색조의 팔레트를 만들 때 HSL이 가장 직관적입니다. 코드 작성 자체는 HEX나 RGB가 더 널리 쓰입니다.
Q. 인쇄용 CMYK 값도 확인할 수 있나요?
이 도구는 웹 색상(HEX·RGB·HSL)에 집중한 도구라 CMYK는 지원하지 않습니다. 인쇄용 색상은 전문 인쇄 소프트웨어의 프로파일 변환을 거치는 것이 정확합니다.

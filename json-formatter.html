JSON 포맷터 & 유효성 검사기

압축된 JSON을 보기 좋게 정렬하거나, 문법 오류가 있는지 바로 확인할 수 있어요.

📖 사용법 보기 ▸
1입력창에 정리하고 싶은 JSON 코드를 붙여넣으세요. 압축되어 있거나 지저분한 형태여도 상관없어요.
2'정렬(Format)' 버튼을 누르면 들여쓰기가 적용되어 구조가 한눈에 보이는 형태로 정리돼요.
3반대로 용량을 줄이고 싶다면 '압축(Minify)' 버튼을 눌러 공백 없는 한 줄 형태로 바꿀 수 있어요.
4문법에 오류가 있다면 상태 표시줄에 어떤 오류인지 바로 안내돼요. 오류가 있으면 결과가 나오지 않아요.
5결과가 마음에 들면 결과창 우측 상단의 '복사' 버튼으로 바로 가져다 쓰세요.
💡 어떻게 되는지 감이 안 오신다면 '예시 불러오기' 버튼을 눌러보세요. 샘플 JSON이 자동으로 입력됩니다.
JSON을 입력하고 '정렬' 버튼을 눌러보세요.

이 도구는 무엇을 하나요?

JSON 포맷터 & 유효성 검사기는 압축되거나 정리되지 않은 JSON 코드를 붙여넣으면 들여쓰기가 적용된 보기 좋은 형태로 정렬해주고, 문법 오류가 있는지 실시간으로 검증해주는 도구입니다. 반대로 정렬된 JSON을 공백 없는 한 줄 형태로 압축(Minify)할 수도 있습니다. 회원가입이나 설치 없이 브라우저에서 바로 사용할 수 있습니다.

왜 만들었나요?

API 응답이나 설정 파일 형태로 JSON을 접하는 일이 개발자가 아니어도 흔해졌지만, 이런 데이터는 대부분 용량을 줄이기 위해 압축된 상태로 제공됩니다. 압축된 JSON은 중괄호와 대괄호가 뒤섞여 있어 구조를 파악하기 어렵고, 문법 오류를 직접 찾아내는 것도 시간이 오래 걸립니다. 코드 에디터를 켜지 않고도 빠르게 확인하고 정리할 수 있는 가벼운 도구가 필요하다고 생각해 만들게 되었습니다.

이런 상황에 유용해요

  • API 응답이 제대로 왔는지 구조를 눈으로 확인하고 싶을 때
  • package.json 같은 설정 파일을 수정하거나 정리해야 할 때
  • JSON 코드에 문법 오류가 있는지, 어디가 잘못됐는지 빠르게 찾고 싶을 때
  • 서로 다른 시스템 간 데이터를 주고받을 때 형식을 확인하고 싶을 때
  • 정리된 JSON을 실제 전송·저장용으로 압축해서 용량을 줄이고 싶을 때

사용할 때 주의할 점

이 도구는 브라우저 안에서만 동작하며, 입력한 JSON 데이터는 서버로 전송되지 않습니다. 다만 회사 업무 관련 민감한 데이터를 다루실 때는 사내 정책상 외부 웹사이트에 데이터를 붙여넣는 것 자체가 제한되는 경우가 있으니 미리 확인하시는 것이 안전합니다. 또한 매우 큰 용량의 JSON(수 MB 이상)을 붙여넣으면 브라우저 성능에 따라 처리 속도가 느려질 수 있습니다. JSON5나 JSONC처럼 주석이 포함된 확장 문법은 표준 JSON 파서로 처리할 수 없어 오류로 인식되니 참고해주세요.

자주 묻는 질문

Q. "Unexpected token" 오류가 발생해요.
대부분 문자열에 작은따옴표(')를 사용했거나, 배열·객체의 마지막 항목 뒤에 불필요한 쉼표가 남아있는 경우입니다. JSON은 큰따옴표만 허용하며 마지막 쉼표를 허용하지 않습니다.
Q. 키(key)에 오류가 발생해요.
JSON은 객체의 키에도 반드시 큰따옴표를 요구합니다. {name: "Kim"} 형태는 JavaScript 객체 리터럴 문법이라 JSON 표준에서는 오류로 처리되니 {"name": "Kim"} 형태로 수정해주세요.
Q. 정렬과 압축, 어떤 걸 써야 하나요?
사람이 읽고 분석해야 할 때는 정렬(Format)을, 실제 전송하거나 저장 공간을 아껴야 할 때는 압축(Minify)을 사용하시면 됩니다. 데이터 자체의 의미는 동일합니다.
